# Informe del Proyecto

Aquí va el informe en Word que se actualiza semana a semana.

## Instrucciones
- Cada semana, actualizar el documento con el avance correspondiente.
- Guardar el archivo con el nombre: Informe_SemanaX.docx (reemplazando X por el número de semana).
- Antes de subir cambios, avisar al grupo para evitar sobrescribir el trabajo de otro compañero.
