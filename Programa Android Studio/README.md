# Programa en Android Studio

Aquí va el proyecto de la aplicación móvil desarrollado en Android Studio.

## Instrucciones
- Abrir esta carpeta directamente desde Android Studio(recordar que es la versión Android Studio Panda 2 | 2025.3.2 3 de marzo de 2026) como proyecto existente.
- Antes de programar, hacer `git pull` para traer los últimos cambios.
- Hacer commits pequeños y frecuentes, con mensajes claros de qué se hizo.
